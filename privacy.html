acamail-monitor — Privacy Policy

Last updated: 2026-10-09

What this is

acamail-monitor is a personal automation tool used by a single person (the owner) on their own computer to organize their own Gmail and Google Calendar. It is not offered to the public. No one other than the owner uses it.

Google data accessed

  • Gmail (read-only): build a private morning summary; read links the owner mails to themselves; read one owner-chosen newsletter label.
  • Gmail (modify): apply labels to the owner's incoming mail according to sender rules the owner wrote. It never sends mail, never deletes mail, and never moves mail to trash.
  • Google Calendar (read-only): show today's events in the morning summary.

How data is used and stored

  • Everything runs on the owner's own computer. Results are saved as notes in the owner's private note archive.
  • Access tokens are stored only on that computer and are never uploaded or shared.
  • At the owner's direction, the content of selected emails (the newsletter label and self-sent links) may be processed by an AI assistant (Anthropic's Claude) to write summaries for the owner. Nothing else is sent to any third party.
  • Data is not sold, not used for advertising, and not transferred to anyone else.

Google API Services User Data Policy

acamail-monitor's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
